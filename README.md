# Фильмотека
*Консольное приложение для каталогизации фильмов на Java Swing*

📋 О проекте
Программа представляет собой десктопное приложение с графическим интерфейсом, разработанное для систематизации персональной коллекции фильмов. Создано в рамках прохождения производственной практики с целью демонстрации навыков клиентской разработки на Java.

## 📦 Запуск
1. Скачайте архив проекта
2. Запустите `MainFrame.java`
3. Начните работу с каталогом
